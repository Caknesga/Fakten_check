BAware for Chrome
=================

INSTALL
1. Open chrome://extensions in Chrome 127 or newer and turn on Developer mode.
2. Click Load unpacked and choose the faktencheck-ampel folder.
3. Pin BAware from the Extensions menu in the toolbar.
4. Allow access to the demo websites when Chrome prompts you.

CHECK A DEMO PAGE
Open a URL listed in demo-cases.js. The popup opens automatically and shows
a loading state for about three seconds. The traffic light and summary cover
the claims selected for that demo. A prepared rating can appear while the page
text is still loading. A gray light means there is no rating for the page.

READ THE DETAILS
Select View details on the BAware website at the bottom of the popup.
Each demo report lists the reviewed quote, the assessment, and its references.
Any original quote in another language is available below its translation.

HIGHLIGHTS
Once the page text matches the demo quotes, the extension highlights them.
Green means supported, red means false, and yellow means unclear or misleading.
Hover on a quote to see its rating or click the quote to keep its report link open.
Use Check options in the popup to change the highlight setting, or use Hide on
the page to clear the current highlights.

MANUAL CHECK
Open Check options, enter a demo URL, and select Check link. If a website blocks
retrieval in the popup, open that page and check it in its tab.

PRIVACY
The browser reads the visible text of the demo page and compares it to the
prepared quotes. Text stays in the browser and results are cached locally.
